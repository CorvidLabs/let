# let

Every coding agent hides its assets in a private layout, so a Grok session cannot see Claude's worktrees and a Claude session cannot route Cursor's skills. `let` should be the one boring, host-neutral answer to what agent stuff is here and where am I, federating what already exists on disk instead of creating another silo to migrate into. It should feel like a locator rather than a platform: fast, read-only by default, honest about what it cannot see, and stingy with context so agents pull what they need instead of being handed everything. It reads a machine full of transcripts and credentials, so the thing it must never do is leak them.
